# Profile design

This is the profile repository for [ss-sevesh](https://github.com/ss-sevesh).
GitHub displays its root README on that account's overview page.

## Direction

A dark engineering notebook, with cream type, warm orange accents, and mint signals.
The primary action is to explore an actual project or watch its demonstration.
The three animated illustrations communicate speech, vision, and retrieval; they
are decorative and do not claim to show live inference or activity.

Reference research on 2026-10-19:

- [GitHub's profile README instructions](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme).
- [DenverCoder1's profile](https://github.com/DenverCoder1) and
  [typing SVG project](https://github.com/DenverCoder1/readme-typing-svg): animated
  introduction, clear work links, and readable content between visual elements.
- [Platane/snk](https://github.com/Platane/snk): demonstrates that a contribution
  animation can be an SVG image generated by an Action. The optional snake uses
  its SVG-only action pinned to a reviewed full commit; the other artwork is original.

## Editing

- Edit `README.md` to update the introduction and project descriptions.
- Edit `assets/header.svg` for the name, typing line, and network illustration.
- Edit `assets/workbench.svg` for the voice, vision, and knowledge illustrations.
- Edit `assets/footer.svg` for the closing line.
- Original artwork uses SVG/CSS, alongside the attributed contribution snake.
  Animations stop when the browser prefers reduced motion; the
  content remains visible.
- Images scale to their container. Text descriptions and project links remain
  real Markdown outside the images, including on narrow screens and screen readers.
- The optional GIF is a link, avoiding a large initial download. Its preview is
  silent; the linked demo has audio.
- Project descriptions and identity come from the existing public repositories
  and profile, with no invented credentials or performance claims.

GitHub controls the surrounding page. A profile README cannot replace its navigation,
contribution calendar, or entire layout with a custom application.

## Live data and maintenance

`scripts/activity.py` uses Python's standard library and the GitHub CLI. It reads
the contribution calendar and latest public development events; it never invents
commits, publishes private repository names, or counts stars as development.
Dates are sorted newest first; bot events and generated output pushes are excluded.
GitHub's events API can lag by up to six hours. The visible UTC timestamp identifies
the last successful snapshot. Calendar contributions include more than commits.

`.github/workflows/activity.yml` runs on main pushes, manual dispatch, and at minute
17 every six hours. It validates SVGs and tests the generator before publishing
only the generated files to `output`, using the built-in repository token. No PAT
or paid service is needed. Source changes remain on main; scheduled output commits
do not artificially add contributions to the default branch. Actions schedules
can be delayed or disabled by GitHub after prolonged repository inactivity.

Local checks: `python -m unittest discover -s scripts -v`.
Local generation with an authenticated CLI: `python scripts/activity.py`.
To restore a snapshot, revert its commit on `output`; to stop refreshes, disable
the workflow in Actions. Failed fetches or validation do not publish partial updates.
